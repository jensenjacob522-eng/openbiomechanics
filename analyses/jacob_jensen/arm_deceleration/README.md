# Arm Injury Risk Is Driven by Angular Deceleration, Not Peak Load

## Core Thesis
Arm injury risk is better explained by angular deceleration demands during
the arm deceleration phase than by peak joint loading metrics.

## Why Peak Metrics Miss Injury Risk
- Peak values ignore rate-of-change effects
- Passive tissues are viscoelastic and rate-sensitive
- Injuries commonly occur during braking, not propulsion

## Arm Deceleration Focus
This analysis focuses on the post–peak angular velocity phase of:
- Shoulder internal rotation
- Elbow extension

## Key Metrics
- Peak angular velocity
- Peak angular deceleration (most negative)
- Time from peak velocity to 10% of peak
- Deceleration impulse (∫|α|dt)

## Dataset
Driveline OpenBiomechanics pitching motion capture data
